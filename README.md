# After-School App — Frontend (Vue 3 + Vite)

This is the frontend of the After-School web application for CST3144 Full Stack Coursework.

The frontend is built with **Vue.js 3** and **Vite**, and connects to the deployed backend API to display lessons, allow sorting/filtering, manage a shopping cart, and submit orders.

## Live Deployment
GitHub Pages:  
https://kishorkaanth38.github.io/after-school-frontend/

## Technologies
- Vue.js 3  
- Vite  
- JavaScript (ES6)  
- Bootstrap 5 (styling components)  
- Fetch API (communication with backend)
